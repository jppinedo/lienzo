# Box

<Meta of={Stories} />

Container with default or glass style. Supports optional header and footer slots, and dark mode.

On the default type, the header sits in the lighter inner area. Set `headerOutside` to place the header in the outer container, matching the footer. The footer always sits outside the lighter inner area.
