# Lienzo Documentation

**Lienzo** is a React component library built with Storybook. It follows **Atomic Design** (atoms and molecules) and uses **Tailwind CSS** for utility-first styling, aiming for a consistent, scalable design system.

## Quick start

Clone the repo, then run `npm install` and `npm run storybook`. Storybook will be available at **http://localhost:6006**. For detailed setup and requirements, see [Getting started](getting-started.md).
